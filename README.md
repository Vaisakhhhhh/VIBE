# 🎧 VIBE – Immersive eCommerce Web Application for Audio Products

**VIBE** is a full-stack eCommerce web application tailored for a premium shopping experience, focusing on high-quality **headphones** and **speakers**. Designed with a clean and modern interface, VIBE merges powerful backend functionality with thoughtful design to deliver a seamless user experience.

---

## ✨ Key Features

- **🛍️ Immersive Product Browsing**
  - Dynamic product listings and detailed product pages.
  - Category-based navigation and intuitive filtering.

- **🔐 Secure User Authentication**
  - User registration and login with OTP verification using **Nodemailer**.
  - Password hashing and session management for secure access.

- **💳 Seamless Payment Integration**
  - Integrated with **Razorpay** for fast, secure, and hassle-free transactions.

- **👤 User Profile Management**
  - Users can view and update personal information.
  - Manage addresses and view order history from their dashboard.

- **📦 Order History & Tracking**
  - Track all placed orders with status updates.
  - Download invoices and review past purchases.

- **🏦 Wallet System**
  - Built-in wallet for storing refunded amounts.
  - Refunds from cancelled orders are credited to the wallet.
  - Wallet balance can be used for future purchases.

- **🛠️ Admin Dashboard**
  - Inventory management: Add, edit, or delete products.
  - Order management: View and update order status.
  - Sales analytics and dashboard overview.

---

## 🧰 Tech Stack

- **Frontend**: EJS Templating, Tailwind CSS, JavaScript  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Integrations**:
  - Razorpay for payments
  - Nodemailer for OTP and emails

---

## 📌 Project Highlights

- Clean and responsive UI/UX optimized for all devices.
- Real-time validations and dynamic interface using JavaScript.
- Scalable and modular MVC architecture.
- Full-featured wallet and refund handling system.
- Admin control panel with full product and order management.
